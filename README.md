## Problema y objetivo

**Problema:**
Actualmente el proyecto carece de una descripción clara sobre el problema real que resuelve en el entorno de desarrollo, lo cual dificulta que nuevos colaboradores o evaluadores entiendan el propósito principal y el alcance del sistema.

**Objetivo medible:**
Lograr que el 100% de los visitantes del repositorio comprendan el propósito del propósito del proyecto en menos de 2 minutos mediante una documentación estandarizada.

**Siguiente paso:**
Implementar la arquitectura base y la configuración inicial del entorno de pruebas.
